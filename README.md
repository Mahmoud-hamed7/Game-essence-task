# 🎮 Game Essence - Interactive Games Discovery Platform

**Game Essence** is a sleek, responsive gaming database and discovery web application designed to help users explore, filter, and search through a massive library of video games. Powered by free-to-play gaming APIs, the application offers dynamic filtering by platform, genre, and sort criteria, alongside detailed game view modals featuring screenshots, minimum system requirements, and direct play links.

🚀 **Live Demo:** [Game Essence Portal](https://mahmoud-hamed7.github.io/Game-essence-task/)

---

## ✨ Key Features

- 🎯 **Advanced Game Filtering:** Filter video games by platform (PC, Browser, All), category/genre (MMORPG, Shooter, Anime, Strategy, etc.), and sort order (Release Date, Popularity, Relevance).
- 🔍 **Real-time Search:** Instant search functionality to quickly find specific titles across the gaming database.
- 🖼️ **Interactive Game Details Modal:** View rich game details including official screenshots, publisher/developer metadata, system requirements, and direct external game links.
- 📱 **Responsive UI & Animations:** Fluid grid layout with animated dynamic cards, smooth hover effects, and responsive navigation across mobile, tablet, and desktop views.
- ⚡ **Asynchronous Data Handling:** Clean async API requests with structured error handling and loading indicators.

---

## 🛠️ Tech Stack & Libraries

- **Frontend Framework:** JavaScript (ES6+) / HTML5 / CSS3
- **Styling & Components:** Bootstrap 5 / Custom CSS Animations
- **Icons & Graphics:** Font Awesome
- **HTTP Client & API:** Fetch API / Axios (Integrating Free-To-Play Games API)
